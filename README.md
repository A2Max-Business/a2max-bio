# A2Max Bio

Social Hub mobile-first da A2Max — Performance e Inteligência de Negócios.

## Status

🚧 Em desenvolvimento

## Stack

| Item | Tecnologia |
|---|---|
| Framework | Next.js |
| Linguagem | TypeScript |
| Styling | Tailwind CSS |
| Package Manager | pnpm |
| Deploy planejado | Vercel |
| Domínio planejado | `bio.a2max.com.br` |

## Development

```bash
# Instalar dependências
pnpm install

# Servidor de desenvolvimento
pnpm dev

# Lint
pnpm lint

# Build de produção
pnpm build
```
